# Bybit 주문 가용액 보정

작성: Codex, 2026-09-13. 공통 실행 오류 수정이며 새 매매 전략은 아니다.

## 원인

Bybit의 실제 `110007 / ab not enough for new order` 거절을 확인했다.
CCXT 4.4.100의 UNIFIED 코인별 free는 출금 가능액이 비어 있을 때 지갑 잔고에서
포지션과 주문 증거금을 빼서 계산한다. 이 계산에는 미실현손익과 계정 단위 담보
평가가 빠질 수 있다. 총잔고가 존재해도 그 전부를 신규 주문에 쓸 수는 없다.

사고 이후 실계좌에서 과대 계산을 검증했지만, 실패 주문 당시 요청 수량과 잔고
스냅샷이 없어 당시 부족액이나 이 문제가 단독 원인이었는지는 복원하지 못했다.

## 변경

- `AuroraClientAdapter.fetch_available_usdt()`는 신규 진입 검사에만 사용한다.
  계정 모드를 확인한 뒤 잔고를 새로 조회한다. 원본 `fetch_balance()`와 UI, 총잔고
  기반 계획 수량, 사용자가 정한 레버리지 및 진입 비중은 바꾸지 않는다.
- 교차/포트폴리오: Bybit `totalAvailableBalance`를 사용한다. 단위가 USD이므로
  같은 응답의 USDT `usdValue / equity` 자산 평가 비율로 USDT에 환산한다.
  전체 계좌의 USD 값과 USDT 지갑 잔고의 비율은 다중 담보에서 틀리므로 쓰지 않는다.
- 격리: 명시적으로 `ISOLATED_MARGIN`을 확인한 경우에만 지갑에서 포지션 증거금,
  주문 증거금, locked, bonus를 뺀다. 새 지갑 잔고에 포함된 spotBorrow도 제외한다.
- 모드, 필수 숫자, 환산값을 확인할 수 없으면 None으로 구분한다. NaN/무한대,
  총잔고 대체, 과거 잔고 재사용은 허용하지 않는다. 실제 0 이하 가용액은 0이다.
- `cap_qty_to_available()`는 미확인/0 이하 가용액이면 신규 진입을 보류한다.
  정상 값에는 기존 90% 여유와 최소 진입 비율을 그대로 적용한다.
- 계정 정보 조회 성공만으로 잔고 인증 실패 누적을 초기화하지 않는다.
  로그는 계정 모드와 환산 가용액 또는 보류 사유를 남기며 인증값은 기록하지 않는다.

## 보호 범위

Origo의 일반 진입 및 Cursus의 시장가/지정가/REVERSE 후 신규 진입이 이 검사를 쓴다.
기존 포지션 청산, SL 등록, 비상청산은 검사 밖에 그대로 둔다. 가용액을 모르는
상태에서도 보호 주문과 청산은 실행되어야 한다. Origo의 기존 force_qty 경로는
변경하지 않는다.

## 검증

- CCXT 4.4.100 실제 잔고 파서와 결정론적 합성 입력으로 모드, 손익, 단위 환산,
  다중 담보, 음수/0, 필수 값 누락, 비정상 숫자, 응답 구조를 검증한다.
- 실제 어댑터를 통한 조회 순서, 매 진입 재조회, 인증 실패 누적, 취소 전파와
  기존 총잔고 응답 불변을 검증한다. 추가 테스트는 mock 라이브러리를 쓰지 않는다.
- 두 모델의 실제 진입/보호 메서드에 합성 입력을 넣어 신규 진입만 차단됨을 검증한다.
- 기존 전략 테스트의 총잔고만 있는 합성 잔고 5곳에는 명시적인 free를 추가했다.
  테스트 통과를 위해 운영 코드의 총잔고 대체 경로를 되살리지 않는다.
- 실계좌의 새 원본 응답에서도 USDT 자산 평가 비율과 수정 파서 결과를 검산했다.
  거래소 조회는 읽기 전용이며 사용자 키, 계좌 원본과 진단 파일은 커밋하지 않는다.

## 남는 한계

계좌 단위 동시 주문 예약은 아직 없다. 조회 후 다른 봇/수동 주문, 가격 변동,
거래소 응답 지연이 있으면 부족 거절은 여전히 가능하다. 수량 정밀도 어댑터가
정렬 실패 시 원본 수량을 반환하는 기존 동작도 별도 개선 대상이다.

연구 작업 트리의 `scripts/live_parity.py`는 가용액 제한을 이미 GAPS로 기록하고 있다.
이 변경은 기존 가용액 해석 오류 수정이며 신호/점수/필터 추가가 아니다. 해당
하니스에 계좌 상태 시뮬레이션이 없는 한 이 수정의 수익성 효과를 백테스트로
검증했다고 주장하지 않는다. 점수/구독 설정 정합 검사도 별도로 실행한다.

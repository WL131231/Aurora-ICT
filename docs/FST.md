# FST — Full Self Trading 로드맵

테슬라 FSD(실주행 빅데이터 → 신경망 학습 → 점진 배포)를 Aurora-ICT 에 매핑한
장기 프로젝트. 목표: **실매매·shadow 데이터로 진입 판단을 학습**시키되,
런타임은 룰 기반 원칙(CLAUDE.md #1)을 유지 — 학습 결과는 가중치/룰로 증류 배포.

발의: 파트너(지영민), 2026-06-12. 명명: FST.

## 단계

| 단계 | 테슬라 대응 | 내용 | 상태 |
|---|---|---|---|
| 1. 데이터 플라이휠 | 차량 플릿 텔레메트리 | 진입뿐 아니라 **거른 setup 도** 특징과 함께 기록 (`shadow_setups.jsonl`, verdict 5종) | ✅ 배포 (#280) |
| 2. 자동 라벨링 | 주행 결과 어노테이션 | 기록된 후보의 사후 가격으로 SL/TP 결과를 자동 채점 → 학습 데이터화 | `scripts/fst_label_shadow.py` |
| 3. 오프라인 학습 | 신경망 학습 | 백테스트 후보(11페어×5년) + 실 shadow 데이터로 P(win\|특징) 학습. 1차(6.6k 후보): 모델 AUC 0.55 로 룰(+10.3R)에 패배 — 데이터 확장 후 재도전 | 진행 중 |
| 4. 섀도 평가 | shadow mode | 모델이 라이브에서 **가상으로** 진입 판단 → 실제 룰과 성과 비교 (자금 미투입) | 설계 |
| 5. 증류 배포 | 점진 롤아웃 | 룰을 이긴 부분만 confluence 가중치/임계로 변환해 배포. 봇 런타임에 모델 추론 없음 | — |

## 원칙
- **과적합 방지**: IN(과거)/OUT(최근) 시간 분리 검증, 거래수 임계, 페어 교차 확인 — 흑자 엣지 연구와 동일 기준.
- **룰이 기준선**: 모델은 같은 거래 빈도에서 룰의 총R 을 이겨야 채택.
- **런타임 무모델**: 라이브 봇은 룰만 실행. 학습은 전부 오프라인.

## 현재 데이터 자산
- 백테스트 후보: `data/ml/*.csv` (특징+라벨, `scripts/ml_dataset_gen.py`)
- 실 shadow: 사용자별 `shadow_setups.jsonl` (배포 후 축적 중)
- 가격: `data/*_1m_full.parquet` (11페어 × ~5년 1m)
- 학습/평가: `scripts/ml_train.py` (룰 baseline 비교 포함)
